# Telegram-бот с OpenAI

Ранний прототип на `aiogram` 3.x и клиенте `openai` 0.x. Команда `/start` выводит приветствие, команда `/chat` отправляет запрос в OpenAI. Код использует старый интерфейс Completions. Работа с текущим API и доступными моделями не проверялась.

Точка входа — [`main.py`](main.py). Для запуска нужны собственный токен Telegram-бота и ключ OpenAI.
